# Claude lineage: research model → Claude Opus 5.5

Legend: ✅ well-established · 🔎 recent, verify against a primary source before shipping.

**Signature mechanic: the Constitution.** Claude's Stage 2 food is *Constitution principles*
(RLAIF, where the model critiques itself against written principles). A high Constitution meter
resists toxic smog, jailbreakers, and reward hacking, but a very high setting early on makes you
over-refuse, and users drift away. Balancing helpfulness against harmlessness is the Claude path's core tension.
